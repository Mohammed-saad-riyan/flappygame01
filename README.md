# Make a proper flappy bird game with very good rand

Make a proper flappy bird game with very good randomness and smooth flow through the game

## Features

- Tap on screen should make the bird fly, and a crash with a pipe would end the game

## Getting Started

1. Ensure Flutter is installed: `flutter doctor`
2. Get dependencies: `flutter pub get`
3. Generate code: `dart run build_runner build --delete-conflicting-outputs`
4. Run the app: `flutter run`

## Architecture

This app uses:
- **Riverpod 3.0** for state management
- **go_router** for navigation
- **Drift** for local storage
- **Material 3** design system
